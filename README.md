# 🍲 Food Web App

## 📝 Overview
A 🍲 food web application that allows 👨‍💻 users to view ⭐ thousands of 🍽️ dishes across various 🛍️ categories. Built with **💪 Angular v14**, **🌐 TypeScript**, and **🔄 RESTful API**.

## 🌟 Features
- 👨‍💻 Browse thousands of delicious 🍽️ dishes.
- 🛍️ Explore recipes across different food categories.
- ✨ Fast, responsive, and easy-to-use interface.
- 🔄 Fetches real-time data from a **RESTful API**.
- 🔍 Search for your favorite meals instantly.

## 🍔 Live Demo
Check out the live version here: [Tasty App](https://tasty-1.netlify.app)

## ⚙️ Technologies Used
- **💪 Angular v14** – Frontend framework.
- **🌐 TypeScript** – Strongly typed programming language.
- **🔄 RESTful API** – Backend data fetching.
- **📚 HTML/CSS** – UI styling for a beautiful interface.

## 🛠️ Installation & Setup
If you want to run this project locally, follow these steps:

### ⚡ Prerequisites
- Install **💻 Node.js** and **🛠️ Angular CLI**

### 🔄 Steps
1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/food-web-app.git
   cd food-web-app

2. Install dependencies:
    ```sh
    npm install

3. Run the development server:
    ```sh
    ng serve

4. Open your 💻 browser and navigate to http://localhost:4200/
